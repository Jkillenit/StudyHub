Study Hub — run the app
========================

Double-click:

  Study Hub.exe

This file is created when you run `npm run dist:win` from the parent StudyHub folder (copied from the portable build in `release/`).

You do not need Node.js installed to run Study Hub.exe.

If Study Hub.exe is missing, open the parent folder and run `npm install` then `npm run dist:win` once to build it.
